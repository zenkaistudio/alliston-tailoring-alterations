# Alliston Tailoring & Alterations

Website for Alliston Tailoring & Alterations.

## Files

- `index.html` — Live site (fully self-contained, all images embedded)
- `source/index-original.html` — Original source file
- `assets/logo.jpg` — Business logo
- `assets/logo_graphic.png` — Watermark graphic
- `assets/images/` — Photo gallery images
- `build.py` — Rebuilds `index.html` from source with all images embedded

## Rebuild

```bash
python3 build.py
```
